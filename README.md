## Open Source Contributions
- **[jax-ml/jax #36521](https://github.com/jax-ml/jax/pull/36521)** — Added complex-input support to `jax.scipy.special.gamma` using the Lanczos approximation and reflection formula in Google JAX.
- - **[aqlaboratory/openfold-3 #344](https://github.com/aqlaboratory/openfold-3/pull/344)** — Reworked the MSA output workflow in OpenFold3 (open-source AlphaFold3 reproduction, AlQuraishi Lab) to fix [#31](https://github.com/aqlaboratory/openfold-3/issues/31), where raw ColabFold records were discarded even with `cleanup_msa_dir` disabled. MSA preparation now runs in a unique per-run workspace that saves both raw ColabFold files and OpenFold-formatted alignments by default; added `save_openfold_outputs`, `save_colabfold_outputs`, and `colabfold_output_dir` settings, plus guards rejecting output paths that cleanup could delete, with regression tests and documentation updates.
- **[Azure/azure-sdk-for-python #46137](https://github.com/Azure/azure-sdk-for-python/pull/46137)** — Fixed an `azure-data-tables` bug ([#46014](https://github.com/Azure/azure-sdk-for-python/issues/46014)) where unsupported `TableClient.list_entities(...)` kwargs leaked into the async transport and surfaced as an `aiohttp` `TypeError`; added early SDK-level validation for `query_filter`/`parameters` with clear guidance to use `query_entities`, plus sync/async regression tests.
